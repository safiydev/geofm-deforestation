Detecting Forest Canopy Loss Across Satellite Time Frames

Optical + SAR Multimodal Fusion Pipeline

Deforestation in equatorial rainforests is frequently obscured by cloud cover. GeoFM pairs Sentinel-2 optical multi-spectral data with Sentinel-1 C-band synthetic aperture radar to deliver reliable, weather-independent change detection.

STAGE 01 · INGESTION
Bitemporal Ingestion
Co-registered optical (B2, B3, B4, B8, B11, B12) and SAR (VV, VH backscatter) chips sampled at T1 baseline and T2 monitoring intervals.
STAGE 02 · SIAMESE BACKBONE
Dual-Branch Siamese Encoder
Weight-shared ResNet / ViT branches extract aligned latent manifold embeddings from both observation windows without seasonal bias.
STAGE 03 · FUSION BOTTLENECK
Residual Difference Fusion
Explicit spatial-temporal difference tensor computation combining absolute delta and directional feature transitions.
STAGE 04 · SEGMENTATION
Mask & Uncertainty Head
Lightweight decoder outputs calibrated per-pixel change probability maps and polygon boundary representations.

Synthetic Aperture Radar (SAR) Cloud Penetration

Sentinel-1 C-band microwaves (5.405 GHz) pass through dense cloud decks, smoke, and nighttime darkness. SAR cross-polarization (VH) is sensitive to forest canopy volume scattering; canopy removal causes sharp drops in backscatter volume, providing empirical confirmation even during monsoons.

LoRA Parameter-Efficient Adaptation

By injecting low-rank decomposition matrices ($r=16, \alpha=32$) into attention projections, GeoFM fine-tunes foundation model weights using under 2% of the parameters of full backpropagation, preventing catastrophic forgetting and enabling consumer GPU training.

Olofsson Area-Adjusted Accounting

Simple pixel counting systematically biases deforestation estimates due to classification error. GeoFM implements stratified random sampling error matrices based on Olofsson et al. (2014), producing mathematically unbiased disturbance area estimates with explicit 95% confidence intervals.

Quickstart & Installation

Run GeoFM on your local workstation, cloud GPU server, or headless cluster.

# 1. Clone the repository
git clone https://github.com/safiydev/geofm-deforestation.git
cd geofm-deforestation

# 2. Install package and dependencies
pip install -e .

# 3. Launch the Autonomous Control Room Web Studio
python studio.py --port 8501 --host 0.0.0.0

# Open http://localhost:8501 in your browser
# 4. Run full test verification suite (94 passed)
pytest tests/ -v
