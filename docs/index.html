Optical + SAR Multimodal Pipeline

Sentinel-1 C-band microwaves (5.405 GHz) penetrate persistent tropical cloud decks, while Sentinel-2 optical captures fine canopy reflectance.

Multimodal Ingestion

Co-registered Sentinel-2 (B2-B4, B8, B11-B12) and Sentinel-1 SAR (VV/VH backscatter) chips sampled at T1 and T2 intervals.

Siamese Backbone

Weight-shared dual-branch encoder extracts aligned latent embeddings from both windows with LoRA parameter-efficient adaptation.

Residual Difference

Spatial-temporal difference tensor computes absolute delta and directional feature transitions, isolating true physical canopy loss.

Segmentation Head

Lightweight decoder generates calibrated per-pixel change probability maps and polygon boundary representations.

Quickstart

Clone the repository and launch the local training and compliance workstation in 3 commands.

git clone https://github.com/safiydev/geofm-deforestation.git
cd geofm-deforestation && pip install -e .
pytest tests/ -v                       # 94 tests passed
python studio.py --port 8501          # launch web studio at http://localhost:8501
