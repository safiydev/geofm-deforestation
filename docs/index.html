Interactive Leaflet dark satellite basemap with MMU filtering, severity-coded detection polygons (Critical, High, Medium), and GeoJSON export.

Validate Annex I commodities against the Dec 31, 2020 legal cutoff date, polygon rules (>4ha), and Olofsson et al. (2014) stratified accuracy assessment.

6. Checkpoints & Zoo

Quickstart & Installation

Run GeoFM on your local workstation, cloud GPU server, or headless cluster.

# 1. Clone the repository git clone https://github.com/safiydev/geofm-deforestation.git cd geofm-deforestation # 2. Install package and dependencies pip install -e . # 3. Launch the Interactive Web Training Studio python studio.py --port 8501 --host 0.0.0.0 # Open http://localhost:8501 in your browser
# 4. Run full test verification suite (87 tests) pytest tests/ -v
