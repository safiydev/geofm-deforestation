How It Works

From raw orbital satellite streams to certified compliance dossiers in four simple steps.

STEP 01

Collect

We download paired optical and radar satellite imagery before and after the 2020 legal baseline.

STEP 02

Align

Our dual-branch neural network aligns coordinates down to the individual 10-meter pixel.

STEP 03

Detect

We compare changes over time to isolate true forest loss from harmless seasonal farming.

STEP 04

Certify

We export verified polygon coordinates and audit reports ready for European customs.

The EUDR Mandate

European Regulation (EU) 2023/1115 requires proof that imported goods were not produced on deforested land.

Requirement The Legal Rule How GeoFM Solves It Status
Cutoff Date Zero deforestation after December 31, 2020 Compares present day against the historical 2020 satellite archive ENFORCED

Quickstart

Run training, evaluate test sets, or launch the interactive workstation on your own machine.

git clone https://github.com/safiydev/geofm-deforestation.git
cd geofm-deforestation && pip install -e .
pytest tests/ -v                       # verify test suite
python studio.py --port 8501          # launch web studio (proof-of-concept)

Notice: The local Web Studio is an experimental, untested proof-of-concept. If you want to test and evaluate this project, running our Google Colab Notebook is strongly recommended.
